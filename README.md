# 🌻 Plants vs. Zombies - Basic Java Project

This is a final project for the **Object-Oriented Programming (OOP)** course. This project recreates the classic strategy game Plants vs. Zombies in a basic version, using the Java language and the Java Swing graphics library.

## 🌟 Key Features
* **Basic Character System:** Includes Peashooters, Sunflowers, and Zombies.

* **Real-time Interaction:** Plant trees by clicking the mouse.

* **Resource System:** Collect Sun Points to buy plants.

* **Smooth Logic Handling:** 60 FPS game loop, accurate bullet firing and hitbox collision mechanics.

## 🛠️ Applied Technology & Knowledge
* **Language:** Java (JDK 17+)

* **Interface:** Java Swing & AWT

* **OOP Knowledge:** * Inheritance

* Polymorphism

* Encapsulation

* Abstraction

* **Multithreading:** Using `Thread` and `Runnable` for game loops.
